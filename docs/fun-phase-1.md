# Fun Phase 1 — Scene archetypes & expression

## Reseed (new scene)

**SHIFT + PLAY** (or Shift + transport Play if your KeyStep sends it)

- Picks a **scene archetype**: Fog Bank, Glass Room, Tape Hymn, Deep Floor, Mist Shore, Veil Light
- Variation inside safe parameter ranges
- ~7s morph + brief reverb bloom + e-ink wipe between sigils

## Hold (texture latch)

**Sustain pedal / CC 64** on KeyStep — latches texture drone to lowest held note

## Arp/sequencer

Fast note streams lock texture root to lowest note, add shimmer, duck drone while you play

## Evolve

**SHIFT + RECORD** — slower audible sweeps (filter, reverb, texture, LFO)

## Velocity

Harder notes = brighter filter + slightly louder (still limited)
